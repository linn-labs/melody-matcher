# Research source guidance

Read README.md, docs/RESEARCH.md, docs/COMPONENTS.md, and docs/DATA_AND_RIGHTS.md before changing this repository.

This is unfinished research. Preserve the distinction between source behavior, historical reports, interpretation, and proposals. Do not turn historical comments into current runtime or quality promises.

Do not automatically install dependencies, fetch models/data, call music services, scrape, train, start the harness, or deploy. Static reading and parsing do not require those actions. Obtain explicit task authorization before work with external side effects.

Keep personal data, credentials, audio, weights, databases, logs, and private records out of commits and review metadata. Use synthetic examples and respect external rights. Document preexisting defects; do not silently expand a documentation task into model or product repairs.
