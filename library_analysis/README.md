# Library coverage analysis

[compare.py](compare.py) compares a separately supplied `library.xml` with collected track metadata. The personal input name was generalized; no library export or database is supplied. It can report individual track names and play counts, so its output should remain private.

Its “embedded” classification is based on Deezer match status, not a check of the actual embedding file. Read [Components](../docs/COMPONENTS.md) and [Data and rights](../docs/DATA_AND_RIGHTS.md). This historical tool was not run for the snapshot.
