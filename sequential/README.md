# Timestamped listening-event collection

[Scripts](scripts) collect scrobbles and report progress using the shared database. No sequential dataset, sequence model, or next-song trainer is included. Historical comments describing a sequential training method describe an intention, not the implemented source.

The event schema and missing artifacts are documented in [Components](../docs/COMPONENTS.md). Proposed temporal evaluation and return prediction appear in [Experiments](../docs/EXPERIMENTS.md). Collection has separate [privacy and service-rights requirements](../docs/DATA_AND_RIGHTS.md); the scripts were not run for this release.
